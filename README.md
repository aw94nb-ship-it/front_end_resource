# UI reference library

A shared collection of websites, repositories, and UI ideas for use across projects.

- [website_list.md](website_list.md) is the inbox. Save links or descriptions without deciding what to borrow.
- [catalog.md](catalog.md) is the curated index with tags; it starts empty.
- `references/<name>/notes.md` holds source links, useful details, and reuse conditions, with images in its `screenshots/` folder. The dashboard and landing-page example folders are empty placeholders, not reviewed references.
- `patterns/` holds lessons across references, starting with navigation, forms, and data tables.
- `snippets/` holds small reusable pieces with attribution and license details.
- [skills/ui-reference-library/SKILL.md](skills/ui-reference-library/SKILL.md) defines the collection and reuse workflow. The personal installation makes it available from other repositories.

Try asking:

- “Save this to my UI library: https://example.com — feels clean.”
- “I saw a dashboard with a floating sidebar; save the idea. I don’t have the link.”
- “Find references in my UI library that would fit this project.”

The library lives at `/Users/yunyawang/Git/front_end_resource`. Project-specific design decisions belong in the consuming project, not in the shared inbox. Saving a reference does not require cloning its code or analyzing its design.
